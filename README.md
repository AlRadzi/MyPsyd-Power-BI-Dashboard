# MyPsyD Power BI Analytics Dashboard

An interactive Power BI analytics solution designed to process, model, and visualize digital psychological health profiling metrics across 42 Malaysian government ministries.

---

## 📌 Project Overview
The **MyPsyD** (System Profiling Psikologi Digital) dashboard transforms high-volume psychological profiling datasets into strategic, visual insights. Built to support public sector human resource management and decision-making, it enables continuous monitoring of organizational wellness trends.

---

## ⚙️ Key Features & Work Done
* **Data Modeling & DAX:** Custom Data Analysis Expressions (DAX) created to clean, classify, and analyze complex psychological metrics.
* **Cross-Ministry Reporting:** Interactive visual slicers and reports tailored to track data across 42 ministries.
* **Automated Analytics:** Designed to streamline reporting readiness and ongoing administrative data management.
